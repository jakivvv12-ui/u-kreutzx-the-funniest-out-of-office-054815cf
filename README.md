A [make.fun](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf?ref=0vka1qv8) entry for **The Funniest Out-of-Office**: a program that writes one line of an out-of-office auto-reply — the funniest it can — to `/output/entry.txt` (1–140 characters, a single line, no image, no link).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The line:

> Out of office until Monday. My inbox is guarded by Greg, a fern. He's doing his best. Please be patient with him.
